## Entries

<a id="abstract-class"></a>
### abstract class

- **Definition:** When a class or a class method has the abstract specifier, you cannot create an instance of the class. An abstract class is intended to be used as a superclass, where some members are implemented or specified but not all. Also referred to as a base class.
- **Source:** Epic Games Verse Glossary

<a id="abstraction"></a>
### abstraction

- **Definition:** A programming principle where unnecessary details are hidden from a user where the user doesn't need to understand the hidden complexities. For example, you can put money in a vending machine and get a treat out without understanding how the mechanics function.
- **Source:** Epic Games Verse Glossary

<a id="access-level"></a>
### access level

- **Definition:** The permissions that determine where a member or definition can be accessed. An access specifier declares the access level.
- **Source:** Epic Games Verse Glossary

<a id="access-specifier"></a>
### access specifier

- **Canonical Hebrew:** מציין גישה
- **Definition:** Access specifiers define the access level. The following are all the access specifiers you can use with classes: public: Unrestricted access. internal: Access limited to current module. This is the default access. protected: Access limited to current class and any subclasses. private: Access limited to current class.
- **Source:** Epic Games Verse Glossary

<a id="additive-effect"></a>
### additive effect

- **Definition:** An additive effect is an effect that can be added to an exclusive effect. Additive effects include suspends and decides.
- **Source:** Epic Games Verse Glossary

<a id="agent"></a>
### agent

- **Canonical Hebrew:** סוכן משחק
- **Definition:** An agent can represent either a player or a non-player character (NPC).
- **Source:** Epic Games Verse Glossary

<a id="algorithm"></a>
### algorithm

- **Definition:** A sequence of instructions written to solve a problem or accomplish a task.
- **Source:** Epic Games Verse Glossary

<a id="api"></a>
### API

- **Canonical Hebrew:** API
- **Definition:** An acronym for Application Programming Interface, these are libraries that are generally grouped into sets of callable functions, types, and data structures that allow users to access and interact with Unreal and Fortnite systems.
- **Source:** Epic Games Verse Glossary

<a id="archetype"></a>
### archetype

- **Definition:** An archetype is an instance of a class that is fully defined with values for its fields in a class.
- **Source:** Epic Games Verse Glossary

<a id="archetype-instantiation"></a>
### archetype instantiation

- **Definition:** The process of creating an archetype. Compare to constructor, which can also run logic or other functions.
- **Source:** Epic Games Verse Glossary

<a id="argument"></a>
### argument

- **Definition:** The value assigned to a parameter in a function signature mapped from a function call.
- **Source:** Epic Games Verse Glossary

<a id="assignment-expression"></a>
### assignment expression

- **Definition:** In Verse, an assignment expression stores a value at a mutable location, such as when initializing a variable or changing the value of a variable.
- **Source:** Epic Games Verse Glossary

<a id="async"></a>
### async

- **Definition:** An async expression may take time to evaluate and can complete in the current simulation update or a later one. Functions marked with the `suspends` effect create async behavior and are also called coroutines.
- **Source:** Epic Games Verse Glossary

<a id="async-context"></a>
### async context

- **Definition:** The scope for where an async expression such as a coroutine call is permitted.
- **Source:** Epic Games Verse Glossary

<a id="atomic"></a>
### atomic

- **Definition:** A single unit of code that executes without interruption or observation from other concurrent code. Adjacent immediate, non-async expressions execute atomically within the same simulation update.
- **Source:** Epic Games Verse Glossary

<a id="base-class"></a>
### base class

- **Definition:** A class from which other classes are derived. A class that inherits from a base class has all members and member functions and can have additional properties that are not included in the base class. A base class is also known as a parent class or superclass.
- **Source:** Epic Games Verse Glossary

<a id="base-16"></a>
### base-16

- **Definition:** Hexadecimal (from hexa-, meaning six, and decimal, meaning ten), base-16 (often shortened to hex), is a numbering system that uses 16 symbols, instead of the more familiar 10 symbols in base-10.
- **Source:** Epic Games Verse Glossary

<a id="bidirectional"></a>
### bidirectional

- **Definition:** Functioning in two directions.
- **Source:** Epic Games Verse Glossary

<a id="bind"></a>
### bind

- **Definition:** In computer programming, to bind is to create a connection between two or more programming objects for a specified amount of time. For Fortnite, binding is associating a function with an event. For Verse, to bind is to create a connection between two or more programming objects for a specified amount of time. For example, if you bind a function to a button's InteractedWithEvent, it means that each time a player interacts with that button, the bound function is called. This can refer to the association of a variable with a value or object, or to the association of a handler with an event.
- **Source:** Epic Games Verse Glossary

<a id="block-expression"></a>
### block expression

- **Definition:** A block expression is a way to group expressions as a single expression or to nest a code block. Block expressions behave in a way similar to code blocks.
- **Source:** Epic Games Verse Glossary

<a id="body"></a>
### body

- **Definition:** A block with its own scope that contains the subexpressions of a language element, such as a function body or loop body. Definitions created inside the body are local to that scope unless exposed otherwise.
- **Source:** Epic Games Verse Glossary

<a id="boolean-logic"></a>
### Boolean logic

- **Definition:** A system of logic based on true and false values. In Verse, the `logic` type represents Boolean values, while many control-flow decisions are expressed through success and failure in failure contexts.
- **Source:** Epic Games Verse Glossary

<a id="brackets"></a>
### brackets

- **Definition:** Brackets are used in Verse to specify different kinds of information in the code. Verse uses four sets of brackets. Their uses include but are not limited to: () Parentheses are used for setting parameters in a function signature and arguments in a function call, and for grouping expressions, tuples, and subclasses. [] Brackets (also called square brackets) are used for failable function calls, type specifiers for arrays and maps, and indexing into an array. {} Curly brackets (or curly braces) are used in archetype instantiation, code block formatting, and string interpolation. <> Angle brackets used to add specifiers to identifiers and functions.
- **Source:** Epic Games Verse Glossary

<a id="branch-expression"></a>
### branch expression

- **Definition:** A `branch` expression starts one or more async subexpressions within the current structured concurrency scope while execution continues with the following expression.
- **Source:** Epic Games Verse Glossary

<a id="break"></a>
### break

- **Definition:** An expression that "breaks out" of the current loop and executes the next expression after the loop expression. For more info, see Loop and Break.
- **Source:** Epic Games Verse Glossary

<a id="bug"></a>
### bug

- **Definition:** For Fortnite Creative and UEFN, an incorrect or unexpected behavior in a program. For Verse, a bug is an error in a computer program that causes it to produce an incorrect or unexpected result. Bugs occur during runtime, as opposed to compiler errors, which occur during Verse compile time. The process of identifying and removing bugs is called debugging.
- **Source:** Epic Games Verse Glossary

<a id="built-in"></a>
### built-in

- **Definition:** In some programming languages, something that is built-in is something you can use directly within the language and its standard libraries.
- **Source:** Epic Games Verse Glossary

<a id="built-in-type"></a>
### built-in type

- **Definition:** A built-in type cannot be broken down further, unlike a composite type.
- **Source:** Epic Games Verse Glossary

<a id="c"></a>
### C++

- **Definition:** A popular programming language used in many different applications — especially game engines such as Unreal Engine.
- **Source:** Epic Games Verse Glossary

<a id="cache"></a>
### cache

- **Definition:** A way to store data so that it can be accessed more quickly.
- **Source:** Epic Games Verse Glossary

<a id="call-graph"></a>
### call graph

- **Definition:** A list of the methods in a call stack, with information about each call, such as execution time, time stamps, and the identifier for the function.
- **Source:** Epic Games Verse Glossary

<a id="call-stack"></a>
### call stack

- **Definition:** The call stack is what a program uses to keep track of calls — which functions are running, which have finished, and which are still to come.
- **Source:** Epic Games Verse Glossary

<a id="caller"></a>
### caller

- **Definition:** An expression that makes a call.
- **Source:** Epic Games Verse Glossary

<a id="canceled"></a>
### canceled

- **Definition:** The state of work that is stopped before it completes. In Verse concurrency, losing branches of a `race` are canceled; calling `Cancel()` on a `cancelable` object prevents the associated current or future work from completing.
- **Source:** Epic Games Verse Glossary

<a id="case-expression"></a>
### case expression

- **Definition:** A case expression can control the flow of a program from a list of options. For more information, see Case.
- **Source:** Epic Games Verse Glossary

<a id="ceil"></a>
### Ceil

- **Definition:** A math operation that rounds a rational value up to the closest integer. Compare to Floor.
- **Source:** Epic Games Verse Glossary

<a id="changelist"></a>
### changelist

- **Definition:** A way of tracking changes to a file in Perforce between local files that are stored on your computer and files that are submitted to the server and merged with the source files for the project. A changelist is also called a CL.
- **Source:** Epic Games Verse Glossary

<a id="char"></a>
### char

- **Definition:** A data type that stores a single character.
- **Source:** Epic Games Verse Glossary

<a id="character-encoding"></a>
### character encoding

- **Definition:** Character encoding is the mapping between a text character and data that the computer can understand, called a code point.
- **Source:** Epic Games Verse Glossary

<a id="ci-cd"></a>
### CI/CD

- **Definition:** CI/CD is continuous integration and either continuous delivery or continuous deployment. CI/CD bridges development and application through automation in building, testing and deployment of applications.
- **Source:** Epic Games Verse Glossary

<a id="code"></a>
### code

- **Definition:** Code, sometimes called source code, is the instructions written by a programmer that tells a software program how to operate. Verse source code can be read by the programmer, but not by the computer. Before the computer can read or execute the program, it has to be converted to computer-executable instructions, called compiling. When a programmer says they are coding, they mean they are writing these instructions.
- **Source:** Epic Games Verse Glossary

<a id="code-block"></a>
### code block

- **Definition:** A group of zero or more expressions that forms a body and introduces a scope. Verse supports indented and braced block formats; the chosen format does not change the block's meaning.
- **Source:** Epic Games Verse Glossary

<a id="code-point"></a>
### code point

- **Definition:** A value in the Unicode code space for character encoding.
- **Source:** Epic Games Verse Glossary

<a id="code-sample"></a>
### code sample

- **Definition:** A standalone program, module, or class that demonstrates one or more concepts, classes, functions, or some other aspect of a programming language. Compare to code snippet.
- **Source:** Epic Games Verse Glossary

<a id="code-snippet"></a>
### code snippet

- **Definition:** A snippet is some code, often short, that's usually meant to showcase or implement a specific concept. Code snippets are not full, standalone programs. Code snippets can be copy-pasted into code blocks. Compare to code sample.
- **Source:** Epic Games Verse Glossary

<a id="code-unit"></a>
### code unit

- **Definition:** The minimal bit combination that can represent a unit of encoded text. UTF-8 uses 8-bits for its code unit.
- **Source:** Epic Games Verse Glossary

<a id="coercion"></a>
### coercion

- **Definition:** The conversion of a value into different data type. Type conversions can be implicitly or explicitly made. Implicit conversion. also called coercion, is done automatically.
- **Source:** Epic Games Verse Glossary

<a id="comment"></a>
### comment

- **Definition:** A comment written by the programmer that explains something about the code or the programmer's reason for how something is programmed. While the code itself shows the how of the program, comments are usually added to explain the why. Code comments can appear anywhere in the code and begin with #. When the program runs, code comments are ignored. You can comment a single line by placing a # at the beginning of the line. The return at the end of the line terminates the comment.
- **Source:** Epic Games Verse Glossary

<a id="commit"></a>
### commit

- **Definition:** A commit is when you record a set of changes in code to a version control system. In Verse, a commit is when code effects of a failable expression are made permanent after that expression succeeds.
- **Source:** Epic Games Verse Glossary

<a id="common-type"></a>
### common type

- **Definition:** Common types are types that are built in and used frequently. Common types include any, comparable, float, int, logic, rational, and string.
- **Source:** Epic Games Verse Glossary

<a id="comparison-expression"></a>
### comparison expression

- **Definition:** In Verse, comparison expressions are when you compare two things using one of the inequality operators: <, >, <=, >=, <>.
- **Source:** Epic Games Verse Glossary

<a id="compile"></a>
### compile

- **Definition:** To convert programs from a human-readable language into computer-executable instructions.
- **Source:** Epic Games Verse Glossary

<a id="compile-time"></a>
### compile time

- **Definition:** When source code is converted into machine instructions. Compare to runtime.
- **Source:** Epic Games Verse Glossary

<a id="compiler"></a>
### compiler

- **Definition:** Software that analyzes source code, reports compile-time errors, and converts valid code into a form the computer or runtime can execute. A parser is one part of a compiler, not a synonym for the entire compiler.
- **Source:** Epic Games Verse Glossary

<a id="compiler-error"></a>
### compiler error

- **Definition:** A compiler error is caused by incorrect code use detected by the Verse compiler at compile time. Compare with bugs, which occur at runtime.
- **Source:** Epic Games Verse Glossary

<a id="completed"></a>
### completed

- **Definition:** The state of a task that ran through to completion.
- **Source:** Epic Games Verse Glossary

<a id="component"></a>
### component

- **Canonical Hebrew:** רכיב
- **Definition:** A reusable unit that supplies data or behavior to a larger system. In UEFN Scene Graph, components attach to entities and can provide transforms, rendering, gameplay tags, particle systems, or custom Verse behavior. The exact meaning of `component` depends on the API or system being discussed.
- **Source:** Epic Games Verse Glossary

<a id="composite-type"></a>
### composite type

- **Definition:** A composite data type, sometimes called compound or aggregate, is any type that can be made up of fields or elements (usually named) of primitive types or other composite types. It usually has a fixed number of fields or elements for its lifespan. Verse currently uses the following composite types: struct, class, enum, interface, and module.
- **Source:** Epic Games Verse Glossary

<a id="computes"></a>
### computes

- **Definition:** An exclusive effect indicating that a function is pure with respect to mutable state and returns the same result for the same inputs, subject to the language's effect rules.
- **Source:** Epic Games Verse Glossary

<a id="concatenation"></a>
### concatenation

- **Definition:** Concatenation is when a string is appended (added) to another string. You can use the operator + to concatenate strings.
- **Source:** Epic Games Verse Glossary

<a id="concrete-class"></a>
### concrete class

- **Definition:** A class with a concrete specifier is a way to construct an instance of the class with an empty archetype, meaning that all fields for the class must be defined with an initial value.
- **Source:** Epic Games Verse Glossary

<a id="concurrent"></a>
### concurrent

- **Definition:** Multiple computations that execute in the same effective period of time are concurrent. This would be overlapping logical simulation updates, ticks, and frames, even if potentially spread over physical time, such as on a single processor, and not necessarily parallel.
- **Source:** Epic Games Verse Glossary

<a id="condition"></a>
### condition

- **Definition:** An expression evaluated to decide whether a path should run. In Verse, conditions in `if` and related constructs are commonly failable expressions whose success or failure controls execution.
- **Source:** Epic Games Verse Glossary

<a id="conditional"></a>
### conditional

- **Definition:** An expression that evaluates a condition and executes instructions based on the result of the condition. An example of a conditional is an if expression.
- **Source:** Epic Games Verse Glossary

<a id="constant"></a>
### constant

- **Definition:** A constant is a location where a value is stored, and its value cannot change during the runtime of the program. It's called a constant because it constantly remains the same. Basic syntax for a constant is name : type = value. The name is a name you assign to the constant (known as the identifier). The : says that a type is coming. The = says a value is coming, then the value itself. For example: PlayerSpeed : float = 2.0 This says that PlayerSpeed has a value of 2.0, represented as a decimal value that does not change while the program is running. Constants always have assigned values. The name and type is the declaration, and the initialization is where that value is expressed. Compare to variable. For more information, see Constants and Variables.
- **Source:** Epic Games Verse Glossary

<a id="constrained"></a>
### constrained

- **Definition:** When an expression is constrained, it has set limits.
- **Source:** Epic Games Verse Glossary

- **Source:** Epic Games Verse Glossary

<a id="variable-code"></a>
### variable (code)

- **Definition:** A mutable storage location declared with `var`, for example `var Score:int = 0`. Its value can be changed with an assignment such as `set Score = 10`. Compare to constant.
- **Source:** Epic Games Verse Glossary

<a id="varies"></a>
### varies

- **Definition:** This effect indicates that the same input to the function may not always produce the same output. The varies effect also indicates that the behavior of the function is not guaranteed to stay the same with new versions of its containing package.
- **Source:** Epic Games Verse Glossary

<a id="verbosity"></a>
### verbosity

- **Definition:** A setting to limit how much additional information will show up when a log is generated.
- **Source:** Epic Games Verse Glossary

<a id="verse"></a>
### Verse

- **Canonical Hebrew:** Verse
- **Definition:** A statically checked programming language developed by Epic Games with an emphasis on gameplay programming and used to create custom logic in UEFN.
- **Source:** Epic Games Verse Glossary

<a id="verse-authored-device"></a>
### Verse-authored device

- **Definition:** A device for use in Unreal Editor for Fortnite (UEFN) that is programmed directly using Verse.
- **Source:** Epic Games Verse Glossary

<a id="visual-programming-language"></a>
### visual programming language

- **Definition:** A type of programming language where the programmer uses visual elements by dragging them around and connecting them with other elements to achieve a specific sequence of program instructions.
- **Source:** Epic Games Verse Glossary

<a id="visual-studio-code"></a>
### Visual Studio Code

- **Definition:** Visual Studio Code, also referred to as VS Code, is a source-code editor made by Microsoft for Windows, Linux and macOS.
- **Source:** Epic Games Verse Glossary

<a id="vpl"></a>
### VPL

- **Definition:** See visual programming language.
- **Source:** Epic Games Verse Glossary

<a id="zero-based-numbering"></a>
### zero-based numbering

- **Definition:** A way of numbering where the first element in a sequence would be assigned as 0, rather than 1. This means that the zero position in an index represents 1, the first position represents 2, and so on. Numbering sequences that start at 0 are common in mathematic notation. In programming, that first position in an array is sometimes termed the zeroth position.
- **Source:** Epic Games Verse Glossary
