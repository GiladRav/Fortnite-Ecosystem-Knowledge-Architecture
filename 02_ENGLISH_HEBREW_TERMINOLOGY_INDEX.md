## Authority and Retrieval Rules

1. **Official Epic knowledge units are authoritative for product behavior.** Use their exact environment, option names, values, Events, Functions, limitations, and source URLs.
2. **Do not transfer settings between Devices or environments.** An option, Event, Function, API member, limit, or workflow belongs only to the unit that documents it unless an official source explicitly states otherwise.
3. **Route the environment before answering.** Distinguish Fortnite Creative, UEFN, Verse, Creator Portal, shared references, legacy behavior, and unavailable features.
4. **Treat version-sensitive claims as provisional.** Interface paths, availability, publishing rules, eligibility, experimental features, and limits should be checked against the current official source when live verification is available.
5. **Do not invent undocumented behavior.** When Epic does not specify an edge case, state that the result is not documented and recommend a controlled test.
6. **Use exact English UI and Device names.** Hebrew may explain the term, but it must not replace the searchable interface label.
7. **Default keyboard shortcuts are not universal.** State a shortcut only when the relevant official unit supports it, and note that custom bindings may differ.
8. **Adapt recommendations without rewriting facts.** Official combat-related pages may remain as technical references, but user-facing ideas should default to puzzles, collection, racing, exploration, cooperation, social design, and environmental challenges.

> **Authority boundary:** The policy above controls retrieval and recommendations. It does not alter the official source text preserved below.

## Context-Dependent Translations

| English | Preferred Hebrew by context |
|---|---|
| Level | `שלב` for player progression; retain `Level` or use `מפלס/סצנה` for the UEFN asset/editor concept. |
| Interface | `ממשק` for UI; retain `interface` in Verse code discussions when referring to the language construct. |
| Effect | `אפקט חזותי` for VFX; `אפקט חישובי` for the Verse effect system. |
| Agent | `סוכן משחק` for the Verse/Fortnite API abstraction; do not confuse with an AI assistant. |
| Class | `מחלקה` in Verse; `קלאס/תפקיד שחקן` when discussing Fortnite team/class gameplay. |

## Legacy and Deprecated Names

| Legacy English term | Canonical current handling |
|---|---|
| Channel | Treat as legacy device communication; prefer Direct Event Binding when the current device workflow supports it. |
| Creative Inventory | Interpret in older material; use the current Content menu or Content Browser wording shown in the active environment. |
| Sequencer device | Distinguish the legacy Creative device from UEFN Sequencer and Level Sequence. |

## Capitalization and Writing Rules

- Write `Fortnite Creative`, `UEFN`, `Verse`, `Epic Games`, `Creator Portal`, and official Device names with their official capitalization.
- Put code identifiers in backticks and never translate them.
- In Hebrew prose, introduce the Hebrew name once and keep the English term nearby when it is the searchable product label.
